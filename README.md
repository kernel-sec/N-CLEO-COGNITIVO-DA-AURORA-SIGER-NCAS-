# NUCLEO COGNITIVO DA AURORA SIGER (NCAS)
Protótipo chamado Núcleo Cognitivo da Aurora Siger (NCAS).  O objetivo do sistema será registrar, organizar, consultar e interpretar informações operacionais da colônia, utilizando arquivos texto, arquivos JSON, regras lógicas e prompts estruturados.
(Projeto FIAP)
